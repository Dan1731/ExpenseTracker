# **Minimum Viable Product (MVP)**
---
## **Features**

### **Must Haves**
1) Log-in / Registration form
- Users must be able to create an account
- Users must be able to log in to an existing account
- Users must only be able to access their own data
2) Add, Edit, and Delete Expenses
- Users must be able to add an expense to their account
- Each expense should include
	- Amount
	- Description
	- Category
	- Date
- Users must be able to edit an existing expense
- Users must be able to delete an existing expense

3) View Expenses
- Users must be able to view a history of their expenses
- The expense history should display:
	- Amount
	- Description
	- Category
	- Date
- Users should be able to easily distinguish between expenses
4) Expense Dashboard
- The app must provide users with a dashboard showing their total spending
- The dashboard should summarize the user's expenses in a clear, understandable way

### **Nice to Have**
- Expense filtering by category or date
- Expense sorting
- Monthly spending summary
- Spending breakdown by category
- Search for expenses
- Income tracking and categorization

### **Out of Scope**
- Bank account integration
- Auto expense tracking
- AI spending insights
- Payment processing
